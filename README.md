# 🚀 Smart Student Monitoring System

A cloud-based automation system that tracks student performance and sends real-time email alerts.

## 🔥 Features
- 📊 Live data from Google Sheets
- ⚡ Real-time dashboard
- 📩 Automatic email alerts
- 👥 Multi-user support
- ☁️ Cloud hosted (GitHub Pages)

## 🛠 Tech Stack
- HTML, CSS, JavaScript
- Google Sheets API
- Google Apps Script

## 💡 Use Cases
- Colleges
- Coaching Centers
- Training Institutes
